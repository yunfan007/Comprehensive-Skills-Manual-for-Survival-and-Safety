面向普通平民的极端环境生存与安全技能参考资料

📖 关于本手册
本手册是一份系统性的极端环境生存与安全技能参考资料，其核心目标是为普通平民在面临各类极端环境时提供可操作、可验证、可重复的技能指导。

这不是一本学术著作，也不是仅供阅读的知识读物——它是一本工具书，一本操作手册，一本在关键时刻可以翻出来对照执行的行动指南。

核心理念
🔴 生命至上 —— 任何技能的运用、决策的做出，都以保护生命为首要目标

📚 循序渐进 —— 从基础到高级，从个体到群体，逐步学习掌握

🌍 因地制宜 —— 根据具体环境、自身状况灵活调整运用

💪 持续练习 —— 知识不等于技能，反复练习才能转化为本能反应
