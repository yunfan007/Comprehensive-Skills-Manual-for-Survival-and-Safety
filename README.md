# 极端环境生存与安全综合技能手册

> 一套面向个人与小团队的系统性生存安全行动框架

---

## 📌 项目简介

本仓库收录并维护 **《极端环境生存与安全综合技能手册》** ——一份融合了态势感知、风险管理、野外生存、自卫脱困、团队协同、应急医疗及心理韧性等领域的综合性技术文档。手册旨在帮助使用者在各类极端情境（城市动荡、野外迷失、基础设施崩溃等）中，通过理性决策与标准化操作，最大限度地保障自身与同伴的安全。

手册内容基于实战经验与已验证的技术体系编制，强调 **“认知先行、项目化管理、逐步递进”** 的方法论，并始终遵循 **“最小必要伤害”** 与 **“合法合规”** 的行动准则。

---


## 🎯 适用对象

- 户外运动爱好者、野外作业人员
- 城市安全与应急准备学习者
- 团队安全管理人员
- 任何希望在不确定环境中保持冷静、理性并有效行动的个人

---

## 🧭 内容概览（框架）

手册分为四大板块，循序渐进：

1. **认知与准备** – 环境分类、应激管理、态势感知、信息验证、工具使用
2. **行动与生存** – 导航追踪、痕迹管理、自卫脱困、野外庇护、水源食物
3. **团队与医疗** – 战术协同、伤员转运、慢性病管理、心理韧性
4. **高级场景** – 搜救程序、法律边界、非对抗撤离、综合演练

详细的章节目录请查阅 `manual` 分支中的正文。
