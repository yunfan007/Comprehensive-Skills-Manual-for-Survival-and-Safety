📖 简介
本手册是一本面向 个人与小团队 的系统性生存安全行动指南。内容涵盖态势感知、信息收集与验证、导航与路线规划、痕迹管理、隐蔽与反侦察、自卫脱困、团队战术协同、野外生存、应急医疗、心理韧性建设及通讯信号等核心技能，构建了一套从 危机识别 → 行动响应 → 医疗自救 → 心理维持 → 安全脱困 的完整操作链路。

手册基于实战经验与验证有效的技术体系提炼而成，旨在帮助使用者在 城市动荡、社会骚乱、野外迷失、基础设施崩溃 等极端情境下，最大化自身与团队成员的安全概率。

🛠️ 预设工具与限制
本手册预设使用者 未持有且不依赖任何热武器或远程杀伤性器械，仅以低伤害性、易于获取或制作的工具作为主要手段：

短棍 – 推荐硬木或高强度塑料，长度自地面至手腕高度。

液体喷射器 – 手动加压式，使用辣椒素类刺激剂，造成暂时失能（30‑60 分钟可逆）。

所有工具的使用均遵循 “最小必要伤害” 原则，且仅用于合法自卫场景。

📌 使用原则
认知先行 – 任何行动的质量取决于决策质量，决策质量取决于态势认知的准确度。

项目化管理 – 将生存任务拆解为可执行子任务，明确目标、资源、风险与时间节点。

逐步递进 – 从基础到高阶，从个人到团队，从理论到实操，循序渐进。

法律合规：本手册内容仅供 合法教育与应急准备 使用。实际应用时，必须严格遵守所在地法律法规。

安全训练：所有涉及身体对抗与工具使用的训练，必须在专业监督下进行，并佩戴符合标准的防护装备。

免责条款：手册作者、发布者及贡献者不承担因非法使用或不当操作造成的任何法律后果或人身伤害责任。

禁止滥用：严禁在非自卫情境下使用喷射器攻击任何未佩戴防护的人员或动物。
